# Software Development Project Tracker

An Excel-based project tracking tool designed to monitor software development tasks, deadlines, milestones, priorities, completion status, and team workload.

## Project Overview

This project tracker organizes 35 software development tasks across Frontend, Backend, UI/UX, and QA teams.

## Key Features

- Task ownership and responsibility tracking
- Milestone and deadline tracking
- Priority management
- Completion percentage tracking
- Delay status monitoring
- Conditional formatting for project status
- Project progress dashboard
- Team workload visualization
- Overall project completion tracking

## Tools Used

- Microsoft Excel
- Excel Formulas
- Conditional Formatting
- Data Visualization
- Dashboarding
